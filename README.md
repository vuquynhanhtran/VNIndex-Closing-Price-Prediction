# VN-Stock-ML-Predictions-prj

Dataset is taken from Cafef.vn and squeezed into vninedx.csv file form the original .xslx file in excel.
Downloaded data from 1 Jan 2025 until August 1 2025. The goal of this project is to make predictions on the daily closing price for VNIndex. 
Note that my model is only limited to predicting the VNIndex closing price of the week
